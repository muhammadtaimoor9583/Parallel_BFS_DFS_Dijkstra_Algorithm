ANALYSIS:
---------
1. Execution Time: Shows how long the shortest path calculation takes with different numbers of threads.
   Lower is better. Ideally, more threads should reduce execution time.

2. Speedup: Measures how much faster the parallel version is compared to the sequential version.
   Speedup = Time(1 thread) / Time(n threads)
   Ideal speedup equals the number of threads (linear speedup).

3. Efficiency: Shows how effectively the threads are being utilized.
   Efficiency = Speedup / Number of threads
   Ideal efficiency is 100%. Lower efficiency indicates overhead from thread management.

OPTIMIZATION NOTES:
------------------
- The Dijkstra's algorithm has been parallelized using a priority-queue based approach
- Work distribution is handled through message passing between threads
- Dynamic load balancing is achieved by directing work to threads with less load
- Thread synchronization is managed through mutex locks to prevent race conditions
- Work stealing is implemented to improve load balancing
